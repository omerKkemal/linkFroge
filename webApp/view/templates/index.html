What Is This Abomination?

LinkFroge is a link management system that gives permanent, stable URLs for dynamic services like ngrok tunnels. Basically: You get a pretty link. It points to your ugly ngrok URL. No one notices. Magic.

Permanent Links (The Whole Point)

Generate stable URLs that don't change. Update destination URL without changing the link. Perfect for ngrok, localhost, dev servers, anything dynamic.

  • Stable forever (We promise... mostly)
  • Update without changing (Like magic, but with code)
  • Perfect for dynamic services (You're welcome)

Desktop CLI Agent (The Magic)

Starts ngrok automatically, detects URL changes, sends heartbeats, and auto-recovers when things break. Because things always break.

  • Auto-start ngrok (You're welcome)
  • URL change detection (It's watching...)
  • Heartbeat system (Keeps things alive, like coffee)

Web Dashboard (The Pretty Face)

User-friendly link management with usage statistics and API token management. Because even developers like pretty things.

  • Manage all links (Like a boss)

CLI Agent Options (The Fun Part)

Option What It Does Default
-h, --help Show help message and exit (Read it. Or don't. I'm not your mom.) —
--port PORT Local port to expose via ngrok (Where the magic happens) 55555
--verbose Enable verbose output – shows every retry, status check, and internal thought. (You'll feel like a hacker. You're just watching logs.) False
--service-id SERVICE_ID Your service ID from LinkFroge (Like a name tag for your app) None
--service-token SERVICE_TOKEN Your service token for authentication (Shh... it's a secret) None
--download-ngrok URL Custom URL to download ngrok if missing (Because the default is too mainstream) Official ngrok download
--ngrok-auth-token TOKEN Ngrok auth token (required for authenticated tunnels) (Don't lose it. We won't find it for you.) None
--linkfroge-api URL LinkFroge API endpoint (Where the data goes) http://127.0.0.1:5000/api
--register-service-id Register a new service ID with LinkFroge (First time setup – do this once) False
# Register a new service ID (first time only)
./linkfroge --register-service-id --linkfroge-api https://yourdomain.com/api/service/register

# Run the agent with your credentials
./linkfroge --port 5000 --service-id YOUR_SERVICE_ID --service-token YOUR_TOKEN --linkfroge-api https://yourdomain.com/api/service/update

Pro tip: On Windows, use linkfroge.exe instead of ./linkfroge.
